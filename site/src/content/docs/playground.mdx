aared works three ways: as an HTML element, as a React hook, or from plain
JavaScript (two flavours). Each tab runs a live demo on the right, with the
code you would write on the left. Pick a format, or choose a local file of your own; your choice
follows you between tabs, and nothing is uploaded anywhere. The status line
above each demo says what was opened: how many slides, sheets, or (for Word)
one document. New here? Start with **HTML** — it's a single tag.
